# Morrow Working Demo

This repository contains a purple Morrow prototype plus a secure Vercel API function.

## Services
- GitHub: code storage
- Vercel: website + serverless API
- OpenAI API: image understanding

## Setup
1. Import this GitHub repository into Vercel.
2. In Vercel, go to Project Settings > Environment Variables.
3. Add `OPENAI_API_KEY` with your OpenAI API key.
4. Redeploy.

Never place your API key in GitHub or index.html.
